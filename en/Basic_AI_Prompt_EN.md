# BASIC AI PROMPT
## Template for Process Analysis

---

**PURPOSE:**

Use this prompt in ChatGPT or Claude for quick process analysis.

---

## PROMPT (copy and paste into AI):

```
Analyze the following business process for automation:

PROCESS: [describe process, e.g., "Processing orders from website"]

CURRENT STATE:
• How performed now: [describe]
• Frequency: [times per day/week]
• Time to complete: [hours per week]
• Who performs: [position]
• Cost of mistake: [approximate amount]

TASK:
1. Rate "automatability" (1-10)
2. Suggest tools (Zapier, Make, other)
3. Estimate implementation complexity (low/medium/high)
4. Suggest first steps

Structure answer by points.
```

---

## USAGE EXAMPLE:

**PROCESS:** Sending Welcome email to new customers

**Frequency:** 20 times/week

**Time:** 2 hours/week

**AI will respond:** Automatability 9/10, use Make + Gmail
